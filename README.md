# Tindr for Games

Portfolio project for discovering and matching with games.

## Project structure

- `frontend/` - Next.js, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, React Hook Form, and Zod.
- `backend/` - FastAPI, Python, SQLAlchemy 2, and Alembic.
- `docker-compose.yml` - Local PostgreSQL foundation.

The project will use a modular monolith architecture with API-contract-first development, vertical slices, and continuous frontend/backend integration.

Application code will be added in later iterations.
